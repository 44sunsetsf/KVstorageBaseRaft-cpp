        What changed, in numbers

        The project I started from had no working persistence and waited for the next heartbeat before replicating every write. Same machine, same 3-node setup, median of 3 runs.

        Measured with a C++ client against 3 nodes with fsync on, Docker on an Apple-silicon Mac. "Same settings" snapshots on almost every write, as the original did; "tuned" uses a 1 MB snapshot threshold.
